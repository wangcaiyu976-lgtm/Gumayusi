# 05-XXX主题信息图形设计

可复制的主题信息图形设计工作区。开展具体选题时，将“XXX”替换为主题名称。

## 八阶段工作流
1. **前期调研**：主题背景、研究问题、受众、使用场景、范围与参考案例。
2. **主题内容分析**：与大模型协作拆解主题，分别判断内容组织、图形表达形式、视觉风格、媒介和标签。
3. **数据搜集**：公共数据集、文本文献、自建数据集；记录来源、口径、日期、许可和可信度。
4. **基础数据集构建**：先拆为单字段基础数据集，再清洗、校验并建立数据字典。
5. **叙事框架搭建**：选择多个字段，以稳定ID或明确键值关联，形成叙事数据集、核心观点和阅读路径。
6. **视觉编码**：点线面体、色彩、字体、行距、字距、图像图形、统计图形、ISOTYPE、版式和视觉风格。偏重设计表达。
7. **信息轮盘测试**：预留测试目标、材料、反馈、问题和迭代记录；测试方法后续补充。
8. **设计实施**：草图、源文件、过程版本、最终输出、展示和交付。

## 主题内容分析：必须区分三个维度
- **内容组织／信息逻辑**：编年型、层级型、编目型、字母表型、地理型等，回答内容关系如何组织。
- **信息图形表达形式**：文字型、词云型、照片型、地图型、统计图形型、图画符号／ISOTYPE型、流程型、组合型等，回答信息通过什么形式呈现。
- **视觉风格／媒介**：照片纪实、扁平插画、手绘、编辑设计、极简、复古、3D等；海报、长图、网页、动态影像等。
三者可组合，不是同一层级的互斥分类。最终判断应说明证据、主类型、辅助类型和选择理由。

## 单字段基础数据集规范
- 一个基础数据集只表达一个变量／一种数据项；一列只放一种数据。
- 一行是一条观测记录，一个单元格只放该字段的一项值。
- 数据类型可为名义、顺序、量化、日期、地理坐标、文本、图像路径或资源ID。
- 不得在同一列混放名称、数值和说明文字。
- 后续可将“地点名称+GPS”关联成地图定位表，将“地区+年份+GDP”关联成时序比较表；须说明关联键、单位、统计口径和来源。

## 大模型协作规范
保留提示词、对话结论、备选标签、反例、采纳／未采纳意见及理由。大模型建议须经资料、数据可得性和设计目标核验。
