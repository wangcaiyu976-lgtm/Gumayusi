# Gumayusi｜信息图形研究

本仓库用于建立一套以**案例观察 → 数据结构分析 → 统计图形识别 → 视觉编码分析 → 信息架构与视觉叙事总结**为核心的信息图形研究方法。

## 目录

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md)：研究五种信息组织逻辑。文档只保存文字分析与案例链接，不存放案例图片。
- [02-信息图形类型案例](./02-信息图形类型案例/README.md)：按信息图形类型收集案例，并维护案例说明。

## 研究约定

1. **案例优先**：类型定义、规律和方法应从实际案例中观察、比较和归纳。
2. **区分证据与假设**：没有案例支持的内容标记为“待案例验证”，不写成已确认原则。
3. **双层文档**：01 记录跨案例归纳出的数据逻辑；02 记录具体案例及其分析。
4. **持续修订**：新案例出现后，更新对应案例文档，并检查是否需要修订 01 中的定义、原则和判断方法。
5. **案例链接**：01 通过相对 Markdown 链接指向 02 中的案例说明；图片只在案例目录中保存一次。

## 每个案例的统一分析维度

- A. 基本的数据逻辑：核心数据实体、字段、数据关系、排序或组织规则。
- B. 统计图形与计算方式：使用了哪些统计图形、统计口径、计算或转换方式；若无统计计算，明确说明。
- C. 视觉编码：点、线、面、体、位置、长度、面积、方向、符号、文字、色彩等如何编码信息。
- D. 数据／信息架构：信息如何分组、分层、排序、关联及组织。
- E. 视觉叙事架构：读者从哪里开始、按什么路径阅读、如何理解重点与结论。

> 说明：图形外观相似不代表数据逻辑相同；判断类型时优先看信息的主要组织依据，而不是只看使用了哪一种图表。
