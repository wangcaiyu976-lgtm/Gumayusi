# 08-设计实施

## 实施流程
1. 锁定数据版本与叙事结构。
2. 建立网格、版面尺寸、阅读方向与信息层级。
3. 制作图形组件、图标/ISOTYPE符号、地图或统计图表。
4. 按视觉编码规范应用色彩、字体、线条、图像和留白。
5. 完成标题、注释、来源、图例、单位与版权标注。
6. 校验数据与图面一一对应，检查比例、单位、排序、标签、可读性。
7. 导出不同媒介版本并记录版本号。

## 建议文件夹
source（源文件/代码/素材许可）、drafts（草图与迭代稿）、exports（最终PDF/PNG/SVG）；另建production_log.md记录软件版本、画布尺寸、色彩模式、导出参数和修改记录。
