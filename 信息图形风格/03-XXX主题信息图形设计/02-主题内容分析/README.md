# 02-主题内容分析

与大模型协作拆解主题，形成可验证的内容结构和标签组合。大模型输出是研究假设，不是事实来源；重要判断必须回到可靠资料核验。

## 分析步骤
1. 拆解核心对象、子主题、事件、地点、人物、指标、关系和争议。
2. 判断主要数据组织逻辑：编年型、层级型、编目型、字母表型、地理图形型；可设主次逻辑并说明依据。
3. 独立判断表达标签：平面、照片、插画、文字型、地图型、图表型、流程图、时间轴、比较图、词云、解剖图、图标阵列、ISOTYPE符号表达等。
4. 为候选标签说明适用内容、所需字段、读者任务与局限。
5. 形成内容大纲、信息层级和关键叙事问题。

## 标签维度（不可混为一层）
- **数据逻辑**：编年、层级、编目、字母表、地理。
- **内容关系/图形结构**：时间轴、流程、比较、分类树、地图、网络、矩阵、列表、词云、统计图表。
- **视觉风格/素材**：平面、照片、插画、手绘、3D、文字主导、图标主导。
- **编码方法**：位置、长度、面积、角度、色彩、形状、文字、照片、ISOTYPE符号等。

## 必须产出
- 主题内容拆解表.csv
- 标签判断与理由.md
- 内容结构图.md
- 与大模型沟通记录.md（保留提示、输出、人工核验与修订）
