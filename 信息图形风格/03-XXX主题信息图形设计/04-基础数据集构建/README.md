# 04-基础数据集构建

## 核心规则
**一列只允许一个字段；一个单元格只允许一个值。** 值可以是名义数据、量化数据、日期、坐标、图像路径或文本字段。不要在一个单元格中塞入多个类别、多个数字或混合内容。

## 子目录
- 01-原始数据：原始下载/采集文件，只读保存。
- 02-清洗数据：字段规范化、去重、格式统一、缺失处理。
- 03-转换数据：合并、编码、聚合、指标计算和可视化专用数据。

## 数据表设计
- 每张表一类实体/观测单位，设置稳定主键（entity_id、event_id、place_id等）。
- 一列一个变量；多对多关系单独建关系表。
- 图像存文件，表中保存image_id/path/来源，不把图片二进制塞进CSV。
- 长文本可独立文件，表中保存text_id/path/来源；文本作为分析对象时，按明确规则拆分记录。
- 坐标拆为latitude与longitude；日期统一格式；量化值与单位分列。
- 缺失值使用空值并在字典中说明，不用“无”“未知”“0”混淆。

## 数据状态
original（原始）、cleaned（清洗）、derived（转换/计算）、transcribed（图面转录）、estimated（估读）、inferred（推断）、unverified（待核验）。
