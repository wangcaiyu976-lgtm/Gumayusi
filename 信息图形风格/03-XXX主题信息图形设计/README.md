## 核心原则
- 先明确选题与受众，再决定信息结构和视觉形式。
- 数据组织逻辑（编年、层级、编目、字母表、地理）与视觉风格（平面、照片、插画、ISOTYPE等）分层判断。
- 每一列只表达一个字段；每个单元格只放一个值。不同数据类型可分表存放，再用稳定ID关联。
- 区分原始、清洗、转换、图面转录、估读和推断数据。
- ISOTYPE作为跨类型的视觉编码/设计方法，不误判为数据组织类型。
