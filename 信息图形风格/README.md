# 信息图形风格与设计方法

本目录研究视觉表达方式、基础设计方法和主题项目实施流程。一级目录统一使用连续编号；每个项目内部再按流程编号。

## 目录
- [01-ISOTYPE基础设计方式](./01-ISOTYPE基础设计方式/README.md)：跨主题使用的图画符号设计与数量表达方法，不是信息图形类型。
- [02-统计图形分析](./02-统计图形分析/README.md)：统计图形的结构、字段、变量、统计口径和视觉编码分析。
- [03-XXX主题信息图形设计](./03-XXX主题信息图形设计/README.md)：可复制的主题信息图形完整工作流。

## 使用关系
先在“01-信息图形数据逻辑”判断数据如何组织，再在“02-信息图形类型案例”选择具体案例标签；本目录负责研究如何将内容和数据转化为视觉表达。ISOTYPE等视觉方法可以跨越多种数据逻辑与图形形式使用。
