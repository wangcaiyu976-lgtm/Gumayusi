# 05-叙事框架搭建

## 目标
从基础数据中选择少量字段，建立明确、可读、可追溯的叙事主题。叙事不是堆数据，而是说明“谁/什么—在哪里/何时—发生了什么/数值如何—为什么值得关注”。

## 叙事组合示例
- 名称 + GPS坐标 → 地图上的地点与空间分布
- 地区名称 + GDP数值 + 年份 → 地区经济规模及时间变化
- 人物 + 事件 + 日期 → 人物经历时间轴
- 类别 + 数量 → 类别比较/构成
- 产品 + 组成部件 + 功能 → 结构解剖/说明图

## 必须产出
- 核心叙事句（一句话表达主题结论）
- 叙事问题与证据链
- 数据字段选择表（字段、来源、作用、可信度）
- 阅读顺序/信息层级/分段标题
- 每个叙事节点对应的数据记录ID
- 缺失证据与不能声称的结论
