# 03-数据搜集

## 数据来源分类
- [01-公共数据集](./01-公共数据集/README.md)：政府开放数据、国际组织、科研机构、开放数据库。
- [02-文本文献](./02-文本文献/README.md)：论文、报告、书籍、新闻、档案、网页文本。
- [03-自建数据集](./03-自建数据集/README.md)：问卷、访谈、观察、人工编码、实地采集。

## 搜集规范
每条来源登记：source_id、作者/机构、标题、URL/DOI/档案号、发布日期、获取日期、覆盖范围、许可/版权、可信度、可用字段、局限。
保留原始下载文件，不覆盖原件；记录版本、下载时间和文件校验信息。文本文献摘录须记录页码/段落位置；人工编码须提供编码规则和复核方式。
