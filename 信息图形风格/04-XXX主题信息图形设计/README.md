## 核心原则
- 先明确选题与受众，再决定信息结构和视觉形式；不能先选一个漂亮图表再硬套数据。
- 数据组织逻辑（编年、层级、编目、字母表、地理）与视觉风格（平面、照片、插画、ISOTYPE等）分层判断。
- 每一列只表达一个字段；每个单元格只放一个值。不同数据类型可分表存放，再用稳定ID关联。
- 区分原始数据、清洗数据、转换数据、图面转录、估读和推断；保留来源与处理记录。
- ISOTYPE作为跨类型的视觉编码/设计方法使用，不将其误判为一种数据组织类型。
- 设计表达优先，但每个视觉编码都必须能说明其对应的数据字段或语义。

## 项目交付检查
- 研究问题、受众、范围、关键结论与来源清单
- 内容结构图及标签判断记录
- 数据来源登记表、数据字典、基础数据表
- 叙事框架与关键叙事句
- 视觉编码规范、图例和版式草图
- 信息轮盘测试记录（未开展时标记待补充）
- 最终设计文件、导出文件、复现说明与版本记录
