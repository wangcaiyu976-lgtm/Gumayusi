# 04-基础数据集构建

## 核心规则
**一列只允许一个字段；一个单元格只允许一个值。** 该值可以是名义数据、量化数据、日期、坐标、图像文件路径或文本字段。不要在一个单元格中塞入多个类别、多个数字或一段混合内容。

## 建议文件
- `raw/`：原始数据，只读保存。
- `cleaned/`：清洗后的规范数据。
- `derived/`：转换、计算、编码后的数据。
- `data_dictionary.csv`：字段名、定义、数据类型、单位、允许值、缺失规则、来源字段。
- `quality_check.md`：重复值、缺失值、异常值、格式与口径检查。

## 数据表设计
- 每张表一类实体/观测单位，设置稳定主键（如 entity_id、event_id、place_id）。
- 一列一个变量；多对多关系单独建关系表。
- 图像数据存文件，表中保存 image_id/path/来源，不把图片二进制塞进CSV。
- 长文本可独立文本文件，表中保存 text_id/path/来源；若文本本身是分析对象，可按明确规则拆分为一条记录一个文本单位。
- 坐标建议拆为 latitude 与 longitude 两列；日期使用统一格式；量化值与单位分列。
- 缺失值使用空值并在字典中说明，不用“无”“未知”“0”混淆。

## 数据状态
标注 original（原始）、cleaned（清洗）、derived（转换/计算）、transcribed（图面转录）、estimated（估读）、inferred（推断）、unverified（待核验）。
