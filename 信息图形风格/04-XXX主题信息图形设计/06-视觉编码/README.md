# 06-视觉编码

本阶段偏重设计表达：将数据字段和内容关系转译为可读、统一、有表现力的视觉系统。每项编码必须说明语义依据、可读性和图例。

## 编码维度
- 点、线、面、体：位置、路径、区域、体积、连接、分组与层级。
- 色彩：色相、明度、饱和度；区分类别色、顺序色、发散色和强调色。
- 文字：字体层级、字号、字重、行距、字距、对齐、文字方向和信息密度。
- 图像图形：照片、插画、图标、纹理、轮廓、示意图、剖面图、地图符号。
- 统计图形：柱状、折线、散点、面积、气泡、矩阵、雷达等，须匹配数据类型和比较任务。
- ISOTYPE：重复符号、符号单位、比例/数量表达、符号语义一致性与图例；明确一个符号代表什么、是否允许半符号、是否有比例缩放。

## 必须产出
- `视觉编码规范.md`：视觉变量→字段/概念→表达含义→使用规则。
- `色彩与字体规范.md`
- `图例与符号规范.md`
- `版式草图/参考图`
- 设计选择理由与可访问性检查（色觉、对比度、字号、阅读顺序）。
