# 01-ISOTYPE基础设计方式

ISOTYPE是跨主题、跨数据逻辑的基础视觉设计方法，不是与编年型、层级型、编目型、字母表型、地理图形型并列的信息图形类型。

## 定位
ISOTYPE（International System of Typographic Picture Education）以图画符号组织和传达社会知识，重点在符号标准化、重复、数量表达、图例说明与视觉叙事。

## 核心研究维度
1. 符号语汇：对象如何抽象为可识别、可重复的图形符号。
2. 符号语法：符号如何排列、分组、连接、比较并形成阅读顺序。
3. 数量表达：一个符号代表多少单位，是否采用半符号/比例符号。
4. 图例系统：符号含义、计量单位、统计基数和例外情况。
5. 视觉一致性：同一对象跨画面保持一致，不同对象如何区分。
6. 叙事与教育：降低阅读门槛，避免过度简化复杂现实。
7. 现代迁移：与地图、时间轴、统计图表、照片、文字和交互媒介组合。

## 使用原则
- 先判断主题的数据逻辑，再决定是否采用ISOTYPE编码。
- ISOTYPE是编码/表达方法，不决定数据属于编年、层级、编目或地理逻辑。
- 必须说明符号代表的实体与单位，不能把装饰图标误当数量符号。
- 符号数量、单符号代表值、统计分母和总量必须分开记录。
- 不得为了画面整齐篡改比例；近似/舍入须明确标注。
- 保留来源、设计者、历史语境和版权信息。
