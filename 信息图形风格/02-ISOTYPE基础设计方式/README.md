# 02-ISOTYPE基础设计方式

> **定位：基础设计方式／视觉编码方法。ISOTYPE不是信息图形类型，不与编年型、层级型、编目型、字母表型、地理图形型并列。**

## 1. 概念与边界

ISOTYPE（International System of Typographic Picture Education）是一种以标准化图画符号组织、解释和传播社会知识的视觉设计方法。它关注如何把对象、数量和关系转化为可识别、可重复、可比较的图形符号。

它不决定信息本身属于哪一种数据组织逻辑，也不限定最终画面必须采用某一种图表。一个编年型项目、地理型项目或统计比较项目，都可以选择ISOTYPE作为视觉编码方法。

## 2. 研究标签

- **符号设计**：对象抽象、轮廓简化、识别性、符号语汇。
- **符号标准化**：同一对象的符号保持一致，不同对象具有可辨识差异。
- **符号排列**：重复、分组、序列、对齐、方向和阅读顺序。
- **数量表达**：一个符号代表的单位、符号数量、部分符号、比例缩放。
- **图例与注释**：符号含义、单位、统计基数、数据范围和例外规则。
- **叙事表达**：通过符号组织呈现比较、变化、分布和社会关系。
- **当代应用**：与地图、时间轴、统计图表、文字、照片和交互界面结合。

## 3. 使用规则

1. 先判断主题的数据组织逻辑，再决定是否使用ISOTYPE。
2. 明确每个符号代表的实体或概念，不把装饰图标误作数据符号。
3. 明确“符号个数”“单个符号代表值”“统计分母”“总量”，四者不能混淆。
4. 如果符号大小不按比例、只用重复数量表示数值，必须在图例中说明。
5. 使用半个符号或其他近似表达时，说明舍入规则及误差。
6. 保留来源、设计者、历史语境和版权信息。
7. 不因视觉整齐而改变真实数据比例；不能确认的编码规则标记为待核验。

## 4. 案例分析记录模板

分析每个ISOTYPE案例时，至少记录：

| 字段 | 说明 |
|---|---|
| case_id | 案例编号 |
| source | 来源与出处 |
| subject | 主题与表达对象 |
| entity | 符号代表的实体 |
| symbol_description | 符号形态描述 |
| symbol_unit | 单个符号代表的单位 |
| quantity_rule | 数量、比例或重复规则 |
| arrangement | 排列、分组与阅读顺序 |
| legend | 图例与注释 |
| data_source | 数据来源 |
| data_status | 原始、转录、估读或待核验 |
| design_notes | 可复用的设计方法与局限 |
