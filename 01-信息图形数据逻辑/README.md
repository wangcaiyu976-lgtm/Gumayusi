## 文档维护规则

- 每种类型统一分析 A—E 五个方面：基本数据逻辑、统计图形与计算方式、视觉编码、数据／信息架构、视觉叙事架构。
- 结论分为“案例观察”“跨案例归纳”“待案例验证”，不把推测写成事实。
- 新增案例时，先在案例目录建立案例说明，再从本目录对应文档链接过去。
- 当多个案例反复呈现同一规律时，再将规律提升为原则；遇到反例时修订原则并注明适用条件。
