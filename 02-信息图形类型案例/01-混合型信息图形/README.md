# 01｜混合型信息图形（Mixed Charts）

本文件夹专门收纳混合型信息图形案例。**每个案例由案例图片与同名 Markdown 说明文档组成，两者直接放在本文件夹内。**一个文件夹可包含多个案例，不为每个案例额外建立子文件夹。

## 文件命名

```text
01-混合型信息图形/
├── README.md
├── 案例-01-案例名称.png
├── 案例-01-案例名称.md
├── 案例-02-案例名称.jpg
└── 案例-02-案例名称.md
```

## 案例分析重点

1. 统计图形承担什么任务：比较、趋势、构成、分布或关系？
2. 是否把统计图形与符号／图示（包括 ISO 风格图形）结合？两者分别表达什么？
3. 点、线、面、大小、位置、色彩和文字是否有一致的编码规则？
4. 图表之间、图表与说明之间如何建立阅读顺序？
5. 哪些元素是数据编码，哪些只是装饰或叙事辅助？

## 重要区分

- 多图表组合：多个统计图表并置，不一定构成完整的信息图形叙事。
- 混合型信息图形：统计表达与符号、文字、视觉编码和叙事架构共同工作。
- 混合统计图（Combo Chart）：通常指同一图表中组合不同图表类型，不等同于本研究中的 Mixed Charts 信息图形类别。
