# 混合型信息图形（Mixed Charts）

## 工作定义

混合型信息图形不是简单地把多个统计图表拼在一起，而是把一种或多种统计图形，与符号、图示（包括 ISO 风格图形）、文字说明和版面组织结合，并通过视觉编码与叙事设计形成整体的信息表达。

## 案例分析重点

1. 统计图形承担什么任务：比较、趋势、构成、分布或关系？
2. 是否把统计图形与符号／图示结合？两者分别表达什么信息？
3. 点、线、面、大小、位置、色彩和文字是否有一致的编码规则？
4. 图表之间、图表与说明之间如何建立阅读顺序？
5. 哪些视觉元素是数据编码，哪些只是装饰或叙事辅助？

## 重要区分

- **多图表组合**：多个统计图表并置，不一定构成完整的信息图形叙事。
- **混合型信息图形**：统计表达与符号、文字、视觉编码和叙事架构共同工作。
- **混合统计图（Combo Chart）**：通常指同一图表中组合不同图表类型，例如柱线组合；它不等同于这里所说的 Mixed Charts 信息图形类别。
