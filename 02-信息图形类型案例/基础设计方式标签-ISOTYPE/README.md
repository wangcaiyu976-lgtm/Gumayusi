# ISOTYPE｜基础设计方式标签

> **本目录是跨类型的基础设计方式标签，不是新增的信息图形类型。**

## 定位与分类边界

ISOTYPE（International System of Typographic Picture Education）是一种以标准化图画符号组织、解释和传播信息的设计方法。它不与“编年型、层级型、编目型、字母表型、地理图形型”等数据组织逻辑并列，也不与本目录中的时间轴、流程图、比较图、解剖图等具体表达形式并列。

一个案例可以先按其主要数据组织逻辑和具体表达形式归档，同时附加“ISOTYPE”标签，说明它采用了这种基础视觉设计方式。

## 标签使用规则

- 只有当案例实际使用了具有明确含义、可识别且相对标准化的图画符号系统时，才添加此标签。
- 单纯出现图标、插画或装饰性小图形，不足以判定为ISOTYPE。
- 记录符号代表的实体/概念、符号形态、排列规则、重复规则及图例说明。
- 如果符号承担数量表达，必须记录单个符号代表值、符号数量、统计分母和总量；不得混为一谈。
- 无法从原图或来源确认的规则标记为“待核验”，不得猜测。

## 案例分析字段

| 字段 | 记录内容 |
|---|---|
| isotype_tag | 是否采用ISOTYPE设计方式 |
| symbol_entity | 图画符号代表的实体或概念 |
| symbol_form | 符号形态及抽象方式 |
| symbol_standard | 是否标准化、重复使用 |
| arrangement_rule | 排列、分组、方向和阅读顺序 |
| quantity_rule | 数量/比例表达规则；不适用则注明 |
| symbol_unit | 单个符号代表的单位；未知则留空并说明 |
| legend | 图例、注释与统计基数 |
| evidence | 图面或来源证据 |
| data_status | 原始、图面转录、估读、推断或待核验 |

## 与案例主分类的关系

- **主分类**：仍按案例的数据组织逻辑与具体表达形式确定。
- **附加标签**：ISOTYPE，用于标记基础设计方式。
- **禁止做法**：不得把案例从原有类型中移出，也不得把ISOTYPE称为第22种信息图形类型。

## 研究重点

1. 图画符号的抽象与识别性
2. 符号系统的标准化与一致性
3. 符号的重复、排列、分组与比较
4. 数量表达、比例规则和图例
5. 图文关系与阅读路径
6. 教育传播、社会叙事与信息简化的边界
7. ISOTYPE方法与地图、时间轴、统计图表等形式的组合
