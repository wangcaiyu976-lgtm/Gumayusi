# 基础数据拆解与数据质量说明

本目录保存从课程 PDF 案例图面中逐项转录的基础数据。采用长表结构：**每一行只表示一个观测值，每个字段单元格只放一个值**。同一案例的多个类别、指标或图例档位必须拆成多行。

## 文件
- [基础数据长表.csv](./基础数据长表.csv)：跨案例的已确认图面数值汇总，仅作总览，不代表任何单一案例的完整数据集。
- 单案例数据表必须保存在对应案例目录的 `data/` 子目录中，并由该案例分析文档链接。当前仅核实到第3页 Gear Timeline 有独立 CSV；其余案例的独立数据表尚未完成。
- 数据列说明见下表。

| 字段 | 含义 |
|---|---|
| case_id | 案例编号（对应原 PDF 页码） |
| page | 原 PDF 页码 |
| entity | 数据实体或图表模块 |
| attribute | 指标/字段名称 |
| value | 单个数值 |
| unit | 单位 |
| data_status | 数据状态；当前为图面转录，不代表原始数据 |
| source_note | 图面位置及必要限定 |

## 数据边界与质量说明
1. 当前文件是**第一批可辨认数值**，不是 64 张案例的完整数据集。
2. P09 的 2、4、8、20、60、68、776 是地图图例档位，不是各县观测值。
3. P22 只录入图面可辨认且较明确的单值；比较组、通勤距离分段、能源消耗等存在辨认或字段映射疑问的内容暂不录入，避免把不确定信息当成事实。
4. P59 记录“每个符号代表该行业工人的5%”这一图例单位；各行业符号数量尚未逐项复核，因此没有推算行业比例。P61 图例文字为“per 500 population”，表示以500人口为统计基数的出生/死亡率表达，不是每个图标代表500人；各地区符号数仍待逐项复核。
5. 这里的数据来自课程 PDF 图像人工转录，不是原作者原始数据。未能确认的来源、统计口径、采集时间及许可信息均不补造。
6. 后续应逐页复核原图、扩展观测行，并在有原始数据时另存原始数据文件；不要覆盖本转录表。

## 与64个案例分析的关系
- 64张案例图及其分析文档已归档，但这不等于64个案例的数据表已完成。
- 每个案例必须有独立的数据拆解文件；若案例是纯示意、解剖或流程结构，也应建立独立的结构化清单，不能把其他案例的数据表重复挂载过来。
- 当前全局CSV只是部分案例的少量图面转录。它不能替代逐案拆解。尚未核对的数值、单位、样本范围、来源与统计口径必须留空并标注待核验，不得估造。
