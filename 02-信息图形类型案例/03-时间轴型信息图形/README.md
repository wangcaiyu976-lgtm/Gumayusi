# 03｜时间轴型信息图形（Timeline Infographics）

本文件夹专门收纳时间轴型信息图形案例。**每个案例由案例图片与同名 Markdown 说明文档组成，两者直接放在本文件夹内。**一个文件夹可包含多个案例，不为每个案例额外建立子文件夹。

## 文件命名

```text
03-时间轴型信息图形/
├── README.md
├── 案例-01-杂志跨页环形时间信息图.png
├── 案例-01-杂志跨页环形时间信息图.md
├── 案例-02-案例名称.jpg
└── 案例-02-案例名称.md
```

## 案例分析重点

1. 时间尺度与粒度是什么？时间从哪里开始、向哪里推进？
2. 节点表示事件、数值采样点，还是其他对象？
3. 线条表示时间顺序、持续时间、关系，还是注释引线？
4. 是否有多个并行对象／类别／泳道？
5. 是否存在统计数值、计算或趋势表达？
6. 阅读路径是线性、分支、环形还是多层？
7. 哪些信息能从图片确认，哪些需要原始资料验证？
