# 时间轴型信息图形（Timeline Infographics）

## 工作定义

以时间点、时间区间或时间顺序为主要组织线索，借助轴线、刻度、节点、区间条、连接线或环形布局呈现事件与变化。时间轴可以是直线、曲线、环形或放射状，不由外形单独决定类型。

## 案例分析重点

1. 时间尺度与粒度是什么？时间从哪里开始、向哪里推进？
2. 节点表示事件、数值采样点，还是其他对象？
3. 线条表示时间顺序、持续时间、关系，还是注释引线？
4. 是否有多个并行对象／类别／泳道？
5. 是否存在统计数值、计算或趋势表达？
6. 阅读路径是线性、分支、环形还是多层？
7. 哪些信息能从图片确认，哪些需要原始资料验证？
