# 文字型／列表型信息图形（Informational / List Infographics）

## 工作定义

以文字、条目、清单或短段落作为主要信息载体，通过标题、分组、编号、符号、图标、色彩和版面层级组织信息。其主要任务通常是解释、罗列、提示、分类或便于快速查找；不要求一定包含统计图表。

## 案例分析重点

1. 基本信息单位是什么：词条、句子、步骤、提示还是条目？
2. 条目如何排序：编号、类别、重要程度、流程还是自由编排？
3. 标题、正文、注释和来源之间有什么层级？
4. 图标、符号和色彩是否承担稳定含义？
5. 读者是连续阅读、快速扫描，还是按类别查找？
