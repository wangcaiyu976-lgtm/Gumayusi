# 02｜文字型／列表型信息图形（Informational / List Infographics）

本文件夹专门收纳文字型／列表型信息图形案例。**每个案例由案例图片与同名 Markdown 说明文档组成，两者直接放在本文件夹内。**一个文件夹可包含多个案例，不为每个案例额外建立子文件夹。

## 文件命名

```text
02-文字型-列表型信息图形/
├── README.md
├── 案例-01-案例名称.png
├── 案例-01-案例名称.md
├── 案例-02-案例名称.jpg
└── 案例-02-案例名称.md
```

## 案例分析重点

1. 基本信息单位是什么：词条、句子、步骤、提示还是条目？
2. 条目如何排序：编号、类别、重要程度、流程还是自由编排？
3. 标题、正文、注释和来源之间有什么层级？
4. 图标、符号和色彩是否承担稳定含义？
5. 读者是连续阅读、快速扫描，还是按类别查找？
6. 是否使用统计图形？如果使用，统计图形与文字列表分别承担什么任务？
