## 1. 01｜五类数据逻辑判断（第一步）
<badge color="success">主类型：编年型</badge>

- **主类型：编年型信息图形。**
- 次要逻辑：没有足够证据认定另一个五类逻辑为次类。
- 判断证据：图面以连续时间阶段为组织主轴，中心阶段标签从“1987-2000”推进到“2000-2006”“2006-2010”“2010”“Now Yulin:2011”及“Future 2012”。
- 判断理由：时间先后与阶段推进决定了信息的主阅读顺序；若移除时间顺序，图形的主要结构和个人经历/发展脉络将失去意义。
- 置信度：高（对主逻辑判断）；阶段内部细节仍有部分文字不清晰。
- 排除：不是层级型主结构（未见父子隶属树）；不是编目型主结构（不是并列条目目录）；不是字母表型（无字母排序）；不是地理图形型（虽出现Yulin地名/地图轮廓，但空间位置不是全图主组织规则）。

## 2. 02｜具体案例标签判断（第二步）
<badge color="info">归档标签：08-时间轴型信息图形</badge>

- **主标签：08-时间轴型信息图形。**
- 同时保留在01-编年型文件夹，是因为它首先属于五类逻辑中的编年型；具体表现形式再标注为时间轴型。
- 选择理由：连续带状路径串联多个时间阶段，并以阶段节点、刻度和事件注释构成时间阅读路径。
- 不归入10-流程图型：没有清晰的操作步骤、分支判断或流程决策结构。
- 不归入19-编年图+编目混合图：图面虽有多条注释，但没有足够证据表明“编目”是与时间并列的主组织逻辑。

## 3. 基础数据集与数据结构
- 数据集类型：**图面转录数据（visual transcription）**，不是原始数据。
- 可确认字段：阶段顺序、阶段标签、阶段类别（过去/当前/未来）。
- CSV仅记录清晰可辨识的中心阶段标签；外围细小事件文字未逐条转录，避免错误识读。
- 未提供的内容：每个事件的准确日期、事件名称、事件描述、作者原始数据、事件之间的因果关系。
- 数据局限：部分标签可能因图片分辨率而存在识读误差；“Yulin”具体指代及其语境仍需高清原图/原始出处确认。

## 4. 数据处理、统计与计算
- 主要数据结构：有序阶段序列（ordinal timeline stages）。
- 主要字段：`sequence`（阶段顺序）、`period_label`（图面阶段文字）、`phase_status`（过去/当前/未来）、`transcription_note`（转录说明）。
- 统计图形：不是典型统计图表；更接近带有阶段刻度与事件注释的连续时间线。
- 计算方式：当前证据未显示数值统计、比例计算或统计汇总；不推断存在统计计算。
- 时间区间长度不能直接比较：各阶段标签区间跨度不同，且未来阶段为预测/规划性质，不能将其与已发生阶段混作同一测量口径。

## 5. 信息图形特性
1. 以一条连续、蜿蜒的带状轨迹串联时间阶段。
2. 时间不是简单的水平直线，而是被转译为环绕、弯曲、连续推进的路径。
3. 以中心留白圆区承载阶段/年份标签，帮助读者在复杂曲线上定位当前所处阶段。
4. 沿路径外缘布置放射状刻度和文字注释，扩展时间节点的信息容量。
5. 蓝、青、绿等色彩在带状路径上形成渐变与分段，强化路径连续性和阶段区分。
6. 末端以开放的弧形延伸至“Future 2012”，形成从过去、现在到未来的开放式结尾。

## 6. 视觉编码提炼
| 视觉变量 | 对应信息 | 作用与读图效果 |
|---|---|---|
| 连续曲线/带状路径 | 时间推进与阶段衔接 | 形成连续阅读路线，避免时间节点彼此孤立 |
| 沿路径的位置 | 阶段先后 | 通过路径方向表达时间顺序 |
| 中心圆形留白 | 阶段年份/时间区间 | 提供阶段定位锚点，稳定复杂曲线的阅读 |
| 外缘短刻度/放射线 | 时间节点或事件定位（具体含义待核实） | 把密集注释从主路径向外展开 |
| 蓝—青—绿渐变/分段 | 路径区段与视觉区分 | 强化连续感，同时帮助区分不同阶段 |
| 外围文字标注 | 事件/经历说明 | 将概括阶段与具体事件关联 |
| 地图轮廓图标 | 可能的地点提示 | 提供空间线索，但不是全图主数据编码 |
| 开放式末端 | Future 2012 | 将叙事从既往经历延伸到未来计划 |

**重要限制：**不能仅凭刻度外观断言每一根短线代表一年、月份或某个量值；需获得原始图例或数据说明后才能确认。

## 7. 信息架构与视觉叙事
- **宏观结构：**单条连续时间路径；沿路径划分多个阶段。
- **阅读入口：**从早期阶段“1987-2000”开始，顺着带状轨迹向后阅读。
- **阅读路径：**早期经历 → 中间阶段 → 2010年前后 → 当前（Now Yulin:2011）→ 未来（Future 2012）。
- **信息层级：**中心时间标签承担阶段识别；外侧小字承担事件补充；色带承担路径连续性与阶段视觉区分。
- **叙事方式：**以个人经历/发展轨迹为线索，将时间阶段组织成连续的成长故事。
- **叙事节奏：**阶段中心标签提供停顿点，外缘密集注释提供局部细读内容。
- **待核实：**外围每条注释的具体事件、注释与刻度的精确对应关系。

## 8. 特性、制作方法与流程
### 可观察到的制作构成
1. 先将经历/事件按时间排序，并归并为若干阶段。
2. 以连续曲线规划时间路径，将阶段顺序映射到路径位置。
3. 将主要阶段名称放入路径附近的中心留白区域。
4. 沿路径边缘安排刻度/引导线，并把详细事件文字放在路径外侧。
5. 通过蓝、青、绿的渐变或分段色带区分路径区段。
6. 在路径末端保留未来阶段，形成开放式时间延伸。
7. 检查时间顺序、标签与刻度的对应关系、文字可读性和整体阅读方向。

## 9. 可迁移的设计方法与评价
- 适用于个人经历、机构发展、项目演进、品牌历史等需要突出连续阶段的主题。
- 用连续弯曲路径替代普通直线时间轴，可增加版面适配性和视觉个性。
- 将“阶段标签”与“事件注释”分层，可兼顾宏观浏览与细节阅读。
- 对密集事件使用外向引导线，能减少文字直接挤占主路径的情况。
- 风险：曲线过度复杂会增加时间方向识别难度；刻度密集会造成文字拥挤；颜色渐变若没有明确分段规则，可能被误读为连续数值大小。
- 改进建议：增加明确的起点/方向提示、图例、关键节点日期；保证颜色对比度；减少交叉引导线；为密集文字设置分区或编号。
