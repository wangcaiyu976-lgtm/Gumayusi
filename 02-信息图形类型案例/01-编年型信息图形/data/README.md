# Gear Timeline 图面转录数据说明

## 文件
- `案例-01-Gear-Timeline-图面转录.csv`

## 数据性质
本表是从课件 PDF 第3页示例图中人工读取的**图面转录数据**，不是作者发布的原始数据，也不是完整事件数据集。仅保留较清晰的中心阶段标签。

## 字段
- `sequence`：图面阶段出现顺序，仅表示阅读顺序。
- `period_label`：按图面可辨识文字转录的阶段标签。
- `phase_status`：根据标签语义标记为过去、当前或未来。
- `transcription_note`：转录与识读限制。

## 使用限制
- 不可将本表用于精确计算时间跨度或统计事件数量。
- 外围细小文字未完整转录；刻度的单位和含义尚未核实。
- `Now Yulin: 2011` 中的 Yulin 具体含义尚待高清原图或原始出处核对。
- 若后续取得作者原始数据，应另存原始数据文件，并保留本表作为图面转录版本。
