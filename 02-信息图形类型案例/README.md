## 案例配对规则
`案例-01-名称.jpg` 必须配 `案例-01-名称.md`，二者放在同一个类型文件夹。案例编号按类型递增。说明文档统一按 A 基本数据逻辑、B 统计图形与计算、C 视觉编码、D 数据／信息架构、E 视觉叙事架构进行分析。

## 分类边界
- 编年型是数据架构逻辑类型；时间轴型是视觉呈现类型，两者分别归档。
- 层级型在 PDF 的五大数据逻辑分类和常用类型页都出现，合并到同一个文件夹。
- PDF第36—37页的“编年图+编目混合图”单独作为混合标签。
- 所有说明只写 PDF 可支持的内容；无法确认的字段、计算或来源明确标注“课件未说明”。
