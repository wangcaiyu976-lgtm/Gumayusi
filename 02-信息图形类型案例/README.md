# 02｜信息图形类型案例

本目录保存案例图片及其案例分析说明。每个案例建立独立文件，图片只在本目录保存；01 中的逻辑文档通过相对链接引用案例说明，不复制图片。

## 案例类型

1. [混合型信息图形（Mixed Charts）](./01-混合型信息图形/README.md)
2. [文字型／列表型信息图形（Informational / List Infographics）](./02-文字型-列表型信息图形/README.md)
3. [时间轴型信息图形（Timeline Infographics）](./03-时间轴型信息图形/README.md)

## 每个案例的记录模板

- 案例编号、名称、来源、作者／机构、年份（未知则标未知）。
- 原始图片或可靠来源链接。
- A. 数据逻辑：数据对象、字段、关系、排序规则。
- B. 统计图形与计算：图形形式、统计口径、计算方法；没有则明确写“未观察到”。
- C. 视觉编码：点、线、面、体、位置、长度、面积、符号、色彩、文字。
- D. 数据／信息架构：分组、层次、索引、关联。
- E. 视觉叙事架构：阅读起点、路径、重点、结论。
- 证据边界：哪些能从图中确认，哪些仍需原始数据或来源验证。

## 分类说明

本目录按案例的主要视觉信息组织方式收纳。一个案例可能同时具有时间、分类、统计图形和文字说明；归档时记录主类型，并在分析中注明混合特征。
