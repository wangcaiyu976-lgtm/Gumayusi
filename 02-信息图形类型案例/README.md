# 02｜信息图形类型案例

本目录是完整的信息图形案例库。**每个类型标签对应一个子文件夹；每个案例由案例图片与配属的同名 Markdown 说明文档组成，二者直接放在该类型文件夹内。**一个类型文件夹可持续收录多个案例。

## 类型体系说明

本案例库同时收录两种不同维度的类型，避免把数据组织逻辑与视觉呈现形式混为一谈：

- **数据逻辑类型**：回答“信息按照什么关系组织”。包括编年型、层级型、编目型、字母表型、地理图形型。
- **表现形式／案例类型**：回答“信息主要以什么视觉形式呈现”。包括混合型、文字型／列表型、时间轴型。

因此，时间轴型与编年型可能出现相同案例，但分类判断依据不同：前者关注时间轴视觉呈现，后者关注时间是否构成数据组织的核心逻辑。一个案例可在分析中标注多个相关特征，但案例图片只需保存一份，避免重复文件。

## 案例文件配对规则（必须遵守）

每个案例在对应类型文件夹内直接保存：

- `案例-01-案例名称.png`：案例图片
- `案例-01-案例名称.md`：该图片的分析说明

下一个案例使用案例-02，依次递增。图片与说明文档必须同名、同目录。一个类型文件夹可以有多个案例，不为每个案例再建立一层文件夹。

每份案例说明统一分析：
A. 基本数据逻辑；B. 统计图形与计算方式；C. 视觉编码；D. 数据／信息架构；E. 视觉叙事架构。

图片尚未收到时，只建立目录说明，不创建虚构图片，也不把空说明冒充已完成案例。

## 与 01-信息图形数据逻辑的关系

01 文件夹保存五种数据逻辑的概念归纳；本目录保存真实案例图片和配属分析文档。01 中的定义文档通过相对链接连接到本目录的案例说明，不重复保存图片。
