# 02｜信息图形类型案例

本目录按**案例标签／类型**划分子文件夹。每个类型子文件夹直接收纳多个案例；每个案例由一张案例图和一份同名说明文档配对组成。

## 目录结构

```text
02-信息图形类型案例/
├── 01-混合型信息图形/
│   ├── 案例-01-案例名称.png
│   ├── 案例-01-案例名称.md
│   ├── 案例-02-案例名称.jpg
│   └── 案例-02-案例名称.md
├── 02-文字型-列表型信息图形/
│   ├── 案例-01-案例名称.png
│   ├── 案例-01-案例名称.md
│   └── ...
└── 03-时间轴型信息图形/
    ├── 案例-01-杂志跨页环形时间信息图.png
    ├── 案例-01-杂志跨页环形时间信息图.md
    └── ...
```

## 必须遵守的归档规则

1. **一个标签对应一个子文件夹**，不为每个案例再建立一层文件夹。
2. **一个案例对应一张图和一份说明文档**，两者放在同一个类型文件夹中。
3. 图片与说明文档使用完全相同的案例编号和名称，只保留扩展名不同，例如 `案例-01-名称.png` 与 `案例-01-名称.md`。
4. 一个类型文件夹可以持续增加多个案例，编号依次递增。
5. 类型文件夹内的 `README.md` 仅作为该类型的目录索引与归档规则，不代替具体案例说明。
6. 案例说明必须分析 A—E：数据逻辑、统计图形与计算、视觉编码、数据／信息架构、视觉叙事架构。
7. 不得用虚构图片、占位图或未经核实的细节冒充真实案例。图片未收到时，在说明文档中明确标注“案例图片待补充”。
