## 每个案例的文件配对方式
`案例-01-第03页.jpg` 与 `案例-01-第03页.md` 必须同名并位于同一个标签文件夹。每个标签可有多个案例。

## 注意
- 编年型是数据架构逻辑；时间轴型是视觉呈现形式，不能混为一类。
- 层级型在 PDF 第6—8页及第30页出现，合并到同一个文件夹。
- 第39—72页主要是艺术与交流、视觉编码、ISOTYPE、内容与风格等原则和示例，不冒充新的五大数据逻辑类型，因此单独归入补充案例文件夹。
