# 字母表型信息图形（Alphabetical Infographics）

以字母顺序或字母索引组织词条、概念或对象，强调排序、索引和检索。

## 案例归档规则

本文件夹收纳此类型的多个真实案例。每个案例必须由一张案例图片和一份同名 Markdown 分析说明组成，二者直接放在本文件夹内，不为单个案例再建子文件夹。

```text
07-字母表型信息图形/
├── README.md
├── 案例-01-案例名称.png
├── 案例-01-案例名称.md
├── 案例-02-案例名称.jpg
└── 案例-02-案例名称.md
```

## 案例分析要求

A. **基本数据逻辑**：识别数据对象、字段、关系、排序／组织规则。  
B. **统计图形与计算方式**：识别统计图形、统计口径、计算方法；未观察到时明确写明。  
C. **视觉编码**：分析点、线、面、体、位置、长度、面积、符号、色彩、文字等。  
D. **数据／信息架构**：分析分组、层级、索引、关联及信息组织方式。  
E. **视觉叙事架构**：分析阅读起点、阅读路径、重点与信息结论。
