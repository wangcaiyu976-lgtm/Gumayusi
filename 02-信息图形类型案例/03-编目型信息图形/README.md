# 03-编目型信息图形（Categorized / Cataloged Infographics）

PDF第10—13页：按类别或条目组织的案例。

## 归档规则
每个案例由一张从原 PDF 导出的案例图片和一份同名 Markdown 说明文档组成，二者直接放在本文件夹内；一个标签可包含多个案例，不为单个案例再建立子文件夹。

## PDF对应案例页
- PDF第10页：编目型信息图形章节示例（案例-01-10页.jpg + 同名 .md）
- PDF第11页：编目型案例图 1（案例-02-11页.jpg + 同名 .md）
- PDF第12页：编目型案例图 2（案例-03-12页.jpg + 同名 .md）
- PDF第13页：编目型案例图 3（案例-04-13页.jpg + 同名 .md）

## 文件命名
- `案例-01-10页.jpg` 与 `案例-01-10页.md`
- `案例-02-11页.jpg` 与 `案例-02-11页.md`
- `案例-03-12页.jpg` 与 `案例-03-12页.md`
- `案例-04-13页.jpg` 与 `案例-04-13页.md`

## 说明
图片必须来自原 PDF 对应页，不重绘、不虚构。说明文档只记录课件能支持的事实；课件没有提供的数据字段、计算方法或来源信息，应明确标注“课件未说明”。
